# Supermarket Billing and Inventory Management System

A CLI-based **Supermarket Billing and Inventory Management System** built with Python 3 and SQLite3. This application enables store operators to manage inventory, record automated sales transactions, apply discounts, calculate taxes, print customer receipts, and review sales reports.

---

## Key Features

- **Inventory Management**:
  - Add new products with unit prices and stock counts.
  - Track current stock levels in real time.
  - Update stock quantities (restock items).
  - Remove items from inventory.
- **Point of Sale (POS) & Billing**:
  - Interactive shopping cart.
  - Real-time inventory check during cart addition.
  - Automatic tax (5%) and customizable discount calculations.
  - Automatic inventory deduction upon completed transactions.
  - Plain-text itemized receipt generator.
- **Sales Reporting**:
  - Store transaction logs in an SQLite database.
  - View overall transaction histories and cumulative store revenue.
